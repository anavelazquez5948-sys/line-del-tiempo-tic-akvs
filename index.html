Línea del Tiempo Histórica de las TIC

Investigación abierta y editable dedicada a las Ciencias de la Información.

Visualización Activa
1936 - Origen Algorítmico

La Máquina de Turing

Alan Turing diseñó el modelo matemático de una computadora universal. Demostró científicamente que un hardware automatizado guiado por un set de instrucciones lógicas (lo que hoy llamamos software) podía resolver cualquier problema matemático computable.

¿Por qué es fundamental para las TIC? Estableció de forma definitiva que las computadoras no debían construirse para un solo propósito, sino que debían ser programables para cambiar su función.
1947 - Física del Silicio

La Invención del Transistor

Desarrollado en los Laboratorios Bell, este diminuto semiconductor reemplazó los gigantescos bombillos o válvulas de vacío. Actúa como un interruptor binario ultrarrápido y microscópico para procesar corrientes eléctricas.

¿Por qué es fundamental para las TIC? Permitió la miniaturización radical. Gracias al transistor pasamos de máquinas que abarcaban habitaciones enteras a microchips capaces de caber en la punta de un dedo.
1969 - Nodos Conectados

Nace ARPANET

El primer sistema de interconexión informática robusta del mundo. Introdujo la conmutación de paquetes: fragmentar los datos enviados para que viajen por múltiples rutas físicas y se reensamblen en el destino, asegurando la comunicación.

¿Por qué es fundamental para las TIC? Es el cimiento estructural y técnico directo sobre el cual se construyó la red de redes que hoy conocemos como Internet global.
1989 - Interfaz Humana

Creación de la World Wide Web (WWW)

Sir Tim Berners-Lee desarrolló el hipertexto interactivo combinando las URL, el protocolo HTTP y el lenguaje HTML en el CERN de Suiza. Creó el lenguaje visual para que cualquier usuario navegue por la red sin dominar código militar o complejo.

¿Por qué es fundamental para las TIC? Internet ya existía, pero la Web lo transformó en una biblioteca multimedia amigable, abriendo la puerta a la democratización masiva de la información.
Actualidad - Computación Avanzada

Big Data e Inteligencia Artificial Neuronal

Hoy las TIC procesan exabytes de datos por medio de redes neuronales artificiales. Los sistemas ya no solo guardan o transfieren archivos, sino que automatizan razonamientos complejos, diagnostican enfermedades y generan código propio.

¿Por qué es fundamental para las TIC? Representa el salto de los sistemas puramente de almacenamiento hacia herramientas autónomas cognitivas que expanden la inteligencia humana a gran escala.
